# Island 0.1.0 — Draft release notes

## Added
- Живое стекло с захватом реального содержимого и fallback на обои.
- Мультимониторность, корректная работа с панелью задач и DPI.
- Ctrl+Alt+Space и командная строка: заметка, напоминание, таймер.
- Напоминания на естественном языке (RU/EN) и пресеты.
- Тихие часы, Focus Assist, snooze 5/10/30.
- Календарь ICS: встреча за 15 минут.
- Погода: 5 дней, осадки, предупреждения, несколько городов.
- Заметки: чек-листы, markdown, экспорт/импорт, синхронизация, стикеры.
- Музыка: текст песни (LRCLIB), устройства вывода, пресеты громкости.
- Темы: тёмная/светлая/системная, акцент из обложки, reduce motion.
- Вкладка «Система»: CPU/GPU/RAM.
- Обновления GitHub с проверкой SHA-256 и подтверждением.

## Changed
- Фиксированный размер окна и один цикл анимации.
- Атомарное сохранение настроек, ротация логов.

## Fixed
- Перекрытие панели задач при автоскрытии.
- Потеря настроек при сбое записи.
- Падение при старте из-за конфликта ключа ресурса «Accent».

## Security
- Санитизация имени файла обновления, установка только после проверки SHA-256.
- Скриншоты очищены от содержимого рабочего стола.

## Known Issues
- Нет действий в системных тостах (кнопки — в кастомном тосте).
- WGC-захват не реализован.
- Запись экрана/звонок/прогресс не показываются.
- Нет LICENSE (решение владельца).
