# NEXT_ACTIONS — Island

## Порядок следующих работ

1. **I. Погода** (следующий крупный шаг): 5-дневный прогноз (daily), вероятность осадков,
   предупреждения по wind/коду погоды, список городов с переключением.
   Файлы: `WeatherService`, `WeatherViewModel`, `WeatherPage`.
2. **E. Календарь**: подписка на ICS-URL в настройках, парсер VEVENT (RRULE, TZID, CANCEL),
   ближайшая встреча за 15 минут в пилюле. Секреты не хранить (URL — в настройках пользователя).
3. **J. Заметки**: чек-листы (`- [ ]`), markdown-рендер, экспорт/импорт JSON,
   синхронизация папкой с блокировкой/мержем по timestamp; закрепление — отдельное topmost-окно.
4. **H. Музыка**: список устройств вывода (IAudioPolicyConfigFactory / MMDevice), пресеты
   громкости, текст песни через LRCLIB (нужна проверка лицензии/доступности и fallback «нет текста»).
5. **K. Темы**: светлая палитра (вынести цвета в ресурсы), акцент из обложки (extract dominant color),
   множитель скорости анимаций и «уменьшить движение» (SystemParameters.ClientAreaAnimation).
6. **D. Мини-активности**: таймер (собственный), запись экрана (WinRT GameBar API недоступен
   для сторонних приложений — использовать WASAPI/GraphicsCapture индикатор?), прогресс загрузок —
   только при наличии достоверного источника; иначе не показывать.
7. **L. Обновления**: публикация релиза, asset с SHA-256 в release notes, загрузка во временный
   файл, проверка хеша, запуск установщика только по кнопке.

## Технический долг
- Проверить DPI 125/150% на реальном мониторе.
- Проверить смену разрешения и выход из сна (WM_DISPLAYCHANGE/WM_SETTINGCHANGE).
- Память ~190 MB: проверить утечки после нескольких часов работы (живое стекло выделяет BitmapSource).
- Тосты не переживают перезапуск приложения (напоминания — да, через LastFired).


## Блокеры и что нужно для продолжения
- **WGC-захват** (вместо CopyFromScreen): попытка «дешёвого» StretchBlt дала регресс CPU и откачена.
  Нужен полноценный WGC: Vortice.Direct3D11 + GraphicsCaptureItem (CreateForMonitor через
  IGraphicsCaptureItemInterop) + Direct3D11CaptureFramePool + копирование текстуры в staging и map.
  План: вынести `ICaptureSource`, WGC как основной путь, CopyFromScreen как fallback, замер CPU
  в стабильных условиях (без браузера/видео), профилировщик.
- **Действия в Windows-тосте**: COM-активатор (`INotificationActivationCallback`), регистрация CLSID,
  обработка аргументов; без этого кнопки в системном тосте «мёртвые» — поэтому оставлены в кастомном.
- **D. Запись экрана**: публичного API «идёт ли запись» нет; можно только эвристики по процессам — не делаем,
  чтобы не показывать недостоверное.
- **D. Звонок**: достоверный сигнал — активная capture-сессия Core Audio (микрофон используется); это
  означает «микрофон занят», не обязательно звонок. Требует решения по формулировке.
- **D. Прогресс загрузок**: универсального источника нет; нужны интеграции с конкретными клиентами.
