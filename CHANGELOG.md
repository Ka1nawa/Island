# Changelog

## 0.1.0 — 2026-11-02

Первый публичный релиз.

### Added
- Живое стекло: захват содержимого за панелью, окно исключено из захвата (WDA_EXCLUDEFROMCAPTURE), fallback на обои.
- Выбор монитора (основной / под курсором / конкретный), корректная работа с панелью задач, DPI и автоскрытием.
- Глобальный хоткей Ctrl+Alt+Space и командная строка быстрых действий (заметка/напоминание/таймер).
- Естественный язык напоминаний (RU/EN) с предпросмотром и пресетами.
- Тихие часы, учёт Focus Assist, отложить на 5/10/30 минут.
- Календарь по ICS-ссылке, встреча за 15 минут (тост + строка в шапке).
- Погода: 5 дней, вероятность осадков, предупреждения, несколько городов.
- Заметки: чек-листы, markdown-превью, экспорт/импорт, синхронизация папкой, автосохранение, стикеры на рабочем столе.
- Музыка: текст песни (LRCLIB), устройства вывода (IPolicyConfig), пресеты громкости.
- Темы: тёмная, светлая, системная; акцент из обложки; скорость анимаций; reduce motion.
- Вкладка «Система»: CPU/GPU/RAM.
- Трей, автозапуск, проверка обновлений GitHub с проверкой SHA-256.

### Changed
- Окно фиксированного размера, анимация одним циклом рендера.
- Настройки сохраняются атомарно (temp + File.Replace), ведётся ротация error.log.

### Fixed
- Островок больше не перекрывает панель задач при автоскрытии.
- Настройки больше не теряются при сбое записи (атомарная запись + лог ошибок).
- Устранён конфликт ключей ресурсов «Accent» (падение при старте).

### Security
- Путь загрузки обновления санитизируется (Path.GetFileName), ассеты ограничены .exe/.msi/.zip.
- Установка обновления только по подтверждению и после проверки SHA-256.

### Known Issues
- Windows-тосты с действиями не реализованы (кнопки остаются в кастомном тосте).
- WGC-захват не реализован, используется CopyFromScreen.
- Запись экрана/звонок/прогресс загрузок не отображаются (нет достоверных источников).
- Нет файла LICENSE — требуется решение владельца.
