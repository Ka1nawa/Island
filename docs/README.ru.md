# Island — кратко по-русски

Динамический островок для Windows 11: пилюля у края экрана, раскрывается при наведении.
Живое стекло, музыка, погода, заметки и напоминания, календарь, быстрые действия и системный монитор.

- Версия 0.1.0, Windows 10 2004+ / 11, x64, .NET 10.
- Установка: распаковать релизный архив и запустить `Island.exe`
  (self-contained не требует .NET; framework-dependent требует .NET 10 Desktop Runtime).
- Сборка: `dotnet build src/Island/Island.csproj`, запуск — `Island.cmd`.
- Данные: `%APPDATA%\\Island`. Телеметрии нет.
