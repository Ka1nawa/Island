### Блок 16 — попытка ускорить захват (StretchBlt) и откат
- Захват сразу в 1/2 через StretchBlt (HALFTONE): CPU 922 ms / 3 s (30,7%) — хуже базовых ~13%.
- 1/4 + COLORONCOLOR: 1109 ms / 3 s (37%) — ещё хуже.
- Решение: откат к CopyFromScreen + downsample; повторный замер дал 1219 ms / 3 s (40,6%),
  то есть в текущих условиях замеры шумные и зависят от нагрузки; сравнение «до/после» в один день
  не подтвердило выигрыш.
- WGC (D3D11 + GraphicsCaptureItem) не реализован: нужен отдельный цикл отладки interop.
